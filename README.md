# Помощник писателя

Веб-приложение для писателя на нейросетях: разбор рукописи, структура книги, перевод,
описание книги, посты для соцсетей, письма издателям, иллюстрации (Google Gemini, Nano Banana)
и озвучка (ElevenLabs).

**Открыть:** https://georgechistov.github.io/writer-assistant/

## Как начать

1. Откройте ссылку и зайдите в «Настройки».
2. Вставьте ключ Gemini. Его можно получить бесплатно: https://aistudio.google.com/apikey
3. Для озвучки вставьте ключ ElevenLabs (начинается с `sk_`): https://elevenlabs.io/app/settings/api-keys
4. В разделе «Рукопись» загрузите главу (.docx или .txt).

## Где хранятся данные

Всё хранится в вашем браузере: рукопись, ответы, картинки, записи и ключи.
Запросы идут напрямую в Google и ElevenLabs, своего сервера у приложения нет.
Чтобы перенести данные на другое устройство, используйте резервную копию
в разделе «Память помощника».
